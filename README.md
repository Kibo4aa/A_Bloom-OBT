# ✨ A_Bloom (OBT)

### **A_Bloom** is a custom **Adobe After Effects** plugin designed to create smooth, cinematic **Glow** and dreamy **Diffusion** effects—helping you blend light and soften highlights effortlessly in your compositions.

![After Effects](https://img.shields.io/badge/After%20Effects-2020%2B-9999FF?style=for-the-badge&logo=adobeaftereffects&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS-blue?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Open%20Beta-orange?style=for-the-badge)
[![BOOTH](https://img.shields.io/badge/BOOTH-adys.booth.pm-FC4D50?style=for-the-badge)](https://adys.booth.pm/)

> [!IMPORTANT]
> **Open Beta Notice:** Once the final version is officially released, this repository will be set to **private**, and the full product will be available for purchase on my [**BOOTH store**](https://adys.booth.pm/).

> [!NOTE]
> **Technical & Rendering Limitations:**
> * **CPU Only (Mercury Software Only):** This plugin currently runs exclusively on the CPU and does not support GPU/CUDA acceleration. It will still work normally even if you enable CUDA in the project settings!
> * **No MFR Support:** **Multi-Frame Rendering (MFR)** is not supported yet in this build.
